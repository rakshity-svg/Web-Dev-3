    Accessibility Notes & Examples

    All interactive controls include labels and ARIA attributes where appropriate. The document uses semantic sections (header, main, nav, footer) and simple HTML headings to help screen reader users navigate.

    Contrast and visual styling are intentionally minimal because no CSS is used. Use your browser's zoom features to test scaling.
